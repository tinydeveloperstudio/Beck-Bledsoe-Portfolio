Hospital Simulator - Java

This project is a solo project that I've been working on during my senior year.

It involves using Java and object-oriented abstract data types and implementing other various data structures to simulate a hospital patient registry and search. The project also explores concepts like time complexity and data storage in structures like arrays and queues.

Portfolio - Website

This website is a project I worked on to showcase my work and experience in a custom made website. The website is coded in HTML, CSS, and JavaScript.

I designed the layout and structure of the website, coded the functionality, and implemented the other various projects I've worked on.

Death Bolt - Mod

Death Bolt is a solo project that I worked on in college. The mod is built for Baldur's Gate 3, and explores custom spell creation and narrative design.

I created the mod using the Baldur's Gate 3 toolkit and used their code to set the spell up from a custom spell mechanic design I created. I then created custom UI using GIMP based on my initial sketches. I brought the art to the toolkit, where I formatted, tested, and published it to mod.io.

Other Projects

Bubble Bends - Game

Bubble Bends is a group project I worked on with my sister for 48 hours during the 2025 Global Game Jam. The game explores immersive design through a combination of animation and code.

I helped design the initial game idea, coded the game's main functionality, and implemented sound effects. I created some sounds and edited other free ones. I also imported the art my sister made and used Unity's animator to finalize the objects.

Bouncy Buds - Game

Bouncy Buds is a solo project I worked on in college. The game explores NavMesh systems, shaders, and visual scripting.

I was inspired by Domango's tutorial on YouTube, and used his shader method with my own filter nodes to make materials. I visual scripted the player's movement and used Unity's NavMesh agents and obstacles for the player's buddy behavior.

Keeper - Game

Keeper is a group project that I worked on in college. The game is inspired by soccer, specifically by the role of goalie/keeper. The game is coded to work with Leap Motion's trackers.

I mainly worked on coding the base systems, designing the UI for the main and pause menus, and integrating my code with other team member's packages.

TMNT Mobs - Mod

TMNT Mobs is a group project that I worked on in college. The mod is built for Minecraft, and explores re-texturing existing mobs within the game.

I created the designs for the new mob's and explained each within the design document. I also made the art and updated files for the designs using Blockbench, configured the modpack to work with Optifine, and tested it all in Curse Forge.

Dragon Knight - Mod

Dragon Knight is a solo project that I worked on in college. The mod is built for Baldur's Gate 3, and it was my first mod for BG3. It explores the capabilities of the toolkit and mod creation.

I created the mod using the Baldur's Gate 3 toolkit and my own custom class design. I used their code to set the class up. I then created the custom UI using free assets, imported the design to the toolkit, where I tested the mod and published it to mod.io.
