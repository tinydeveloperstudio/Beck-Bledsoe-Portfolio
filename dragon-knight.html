Description

Dragon Knight is a project I worked on in my final year while at Milwaukee Area Technical College. This project focuses on gameplay design, technical writing, and in-editor development. I designed the class, created sample UI using free assets from Canvas, built and tested the mod in the Baldur's Gate 3 toolkit, and managed the mod using mod.io.
