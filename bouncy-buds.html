Description

Bouncy Buds is a project I worked on in my final year while at Milwaukee Area Technical College. This project focuses on AI pathfinding, gameplay design & development, visual scripting, and shader creation. Using Unity and C#, I developed the main levels of the game. I also worked on the shader implementation using Unity's shader graphs.
