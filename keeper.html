Description

Keeper is a project I worked on in my first year while at Milwaukee Area Technical College. This project focuses on motion-tracked gameplay design & development. I suggested the game theme of being a soccer goalkeeper to my team, created sample UI using free assets from Canvas, developed gameplay mechanics that interact with motion tracking, and managed the build of the game by implementing all the assets from myself and team members.
