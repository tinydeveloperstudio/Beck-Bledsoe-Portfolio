Description

The Hospital Simulator project is an on-going project I've been working on in my senior year at Carroll University. It is focused on using data structures and object-oriented programming in Java to create a functional patient registry.

GitHub Repository

  • Week 1: Forking the repository on GitHub and setting up the virtual codespace. Implementing the patient, patient registry, and test classes.
  • Week 2: Researching and creating various search methods for patients based on patient ID. Testing those methods with custom tests. Observing how the different methods function with their big-O time complexities.
  • Week 3: Learning about linked lists and recursion and practicing implementation outside of the hospital simulator.
  • Week 4: Developing a working queue system for managing patients based on triage level. Adding enqueue, dequeue, and size methods.
  • Week 5: Continuing the queue system implementation and testing various irregular cases for the methods. Adding bounded queue lines for the triage level based on an input max capacity.
  • Week 6: Finishing the custom test method implementations, adding a second queue style (input restricted queues) and comparing with the current queue implementation (input & output restricted queues).
